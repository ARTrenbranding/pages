SMP 운영 게이트

촬영과 발행은 진행하되, 다른 콘텐츠와 다른 검수 절차를 적용한다. 이 절차를 건너뛴 SMP 게시물은 발행하지 않는다.

발행 전 4단계 검수

  1. D-4 · 편집 1차 — 자막·나레이션에서 금지 표현 스크리닝. 치료 / 완치 / 발모 / 모발 재생 / 영구적 / 평생 유지 / 절대 번지지 않음 / 효과 보장 / 착색 및 유지력이 높아짐 / 탈모 극복.
  2. D-3 · 화면 검수 — 시술 장면, 전후 비교, 바늘 접촉, 혈흔, 두피 질환 오인 화면이 한 프레임도 없는지 확인.
  3. D-2 · 원장 확인 요청 — 완성본을 원장에게 송부. 회신 없이는 발행하지 않는다.
  4. D-0 · 발행 — 가격은 온라인에서 상담가로만 안내. 부위별 기준가는 매장 인쇄물 한정.
1회차 적용 대상: 09-03 릴스 1건. 원장 확인 요청 마감은 09-01. 회신이 없으면 대체 주제 '상담부터 시작하는 이유'(Q3 · C01–C04 O03)로 즉시 교체한다.

HIGH · 당일 발행

08-19 첫 게시물이 촬영 당일

촬영일과 첫 발행일이 겹친다. 오픈·찾아오는 길 카드뉴스는 촬영본 없이 제작 가능하지만, 08-18까지 디자인이 끝나 있어야 한다.

창 과노출과 혼합광

호수 하이라이트와 피부톤을 동시에 살려야 한다. 천장등을 켠 채 진행하면 색온도가 섞여 후반 그레이딩에서 피부가 무너진다.

대안 09:45 구간에서 천장등 OFF 기준 확정. 창 과노출 시 인물 각도 변경 또는 블라인드 반개방. 호수는 노출 브라케팅 별도 확보.

13:20 종료가 오후 예약과 충돌

대안 08-18까지 원장 오후 일정 확인 필수. 축소 시 12:00–12:30 인터뷰를 절대 사수하고 매장·호수는 별도 30분 방문으로 분리.
